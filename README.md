# 仿猫眼电影 / 演出票务系统（Python + Flask + MySQL）

一个可在 **PyCharm** 中直接运行、在浏览器里使用的仿猫眼票务系统，覆盖用户购票与商家运营的完整闭环。

## 一、功能清单

### 普通用户端
| 功能 | 说明 |
|---|---|
| 浏览票品 | 首页按「电影 / 演出」分类浏览，支持关键词搜索，展示封面、名称、简介、票价、上映/演出时间 |
| 票品详情 | 完整介绍、主演/嘉宾、时长、地址、场次列表 |
| 选择场次 | 每个票品多个场次，不同场次不同票价/座位库存 |
| 选座 | 可视化座位图，灰色=已售、黄色=锁定、可选座位高亮，点击挑选 |
| 座位锁定 | 选座提交后座位被锁定并生成待支付订单，防止他人抢购 |
| 提交订单 | 确认票品、场次、座位、价格，生成待支付订单 |
| 在线支付 | 模拟支付（演示环境），支付成功生成电子票券，超时自动取消订单并释放座位 |
| 我的订单 | 区分待支付/已支付/已完成/退票中/已退票等状态 |
| 申请退票 | 填写原因提交，等待商家审核；通过则退款并回收座位 |
| 电子票券 | 支付后生成**订单级统一核销码**（一个订单无论几张票共用一个），线下出示检票；核销后订单显示【已核销】 |

### 商家后台
| 功能 | 说明 |
|---|---|
| 上传/新增票品 | 选择类型（电影/演出），录入名称、简介、地址等；**封面可从电脑上传本地图片**，也可填 URL；**新增的票品显示在列表最下面** |
| 编辑票品 | 修改封面（可重新上传本地图）、介绍等，保存后用户端同步更新 |
| 上架/下架 | 下架后用户无法浏览购买，已购订单与电子票仍有效 |
| 场次/库存/票价 | 添加多个场次，设置时间、票价、座位布局，批量调价，重置座位 |
| 销售订单 | 按时间/票品/状态筛选，查看用户、场次、座位、金额、状态 |
| 退票审核 | 通过则原路退款、回收座位；驳回则恢复订单 |
| 电子票核销 | 输入订单核销码**整单一次性核销**（本订单全部座位），核销后订单状态变为【已核销】；一张订单只能核销一次，重复核销会被拒绝 |

## 二、技术栈

- **后端**：Python 3 + Flask 3
- **数据库**：MySQL（PyMySQL 驱动）
- **前端**：原生 HTML / CSS / JavaScript（Jinja2 模板）
- **认证**：Flask Session + Werkzeug 密码哈希

## 三、项目结构

```
maoyan_ticket/
├── app.py                    # 应用入口，运行 python app.py
├── config.py                 # 数据库与 Flask 配置（改密码在这里）
├── db.py                     # 数据库连接工具
├── init_db.py                # 一键初始化：建库建表+示例数据+测试账号
├── db.sql                    # 数据库脚本（也可手动导入）
├── requirements.txt          # 依赖清单
├── routes/
│   ├── auth.py               # 登录/注册/登出
│   ├── user.py               # 用户端：浏览/选座/下单/支付/订单/退票/票券
│   └── merchant.py           # 商家端：票品/场次/座位/订单/退票审核/核销
├── utils/
│   ├── decorators.py         # 登录/商家权限装饰器
│   └── helpers.py            # 订单号/核销码/超时判断工具
├── templates/                # 用户端页面
│   └── merchant/             # 商家后台页面
└── static/
    ├── css/style.css         # 全局样式
    ├── js/seat.js            # 选座交互
    └── uploads/              # 票品封面上传目录（上传的本地图片存在这里）
```

## 四、环境准备

1. **安装 MySQL**（若未安装）：官网下载 MySQL Community Server，安装时记住 root 密码。
2. **安装 Python 3**（本项目测试于 Python 3.13）。
3. **安装依赖**（在项目目录下执行）：

```bash
pip install -r requirements.txt
# 或手动安装：
pip install Flask PyMySQL
```

> 可选：如需在电子票页展示**真实二维码**，再安装 `pip install qrcode pillow`（不装也不影响，核销码可直接使用）。

## 五、具体操作步骤（PyCharm 运行）

### 第 1 步：配置数据库密码
打开 `config.py`，把 `DB_PASSWORD` 改成你本机 MySQL 的 **root 密码**：

```python
DB_PASSWORD = '你的MySQL密码'
```

### 第 2 步：初始化数据库
在 PyCharm 底部 **Terminal** 中，进入项目目录并运行：

```bash
python init_db.py
```

脚本会自动：创建数据库 `maoyan_ticket`、建 8 张表、写入示例票品/场次/座位，并创建两个测试账号（密码均为 `123456`）：
- 商家账号：`shop01`
- 用户账号：`user01`

> 也可以手动导入：在 Navicat / MySQL Workbench 中执行 `db.sql`，再单独插入测试账号。

### 第 3 步：启动应用
```bash
python app.py
```
看到 `Running on http://127.0.0.1:5000` 即启动成功。**保持该进程运行，不要关闭**。

### 第 4 步：浏览器访问
| 入口 | 地址 |
|---|---|
| 用户端首页 | http://127.0.0.1:5000/ |
| 商家后台 | http://127.0.0.1:5000/merchant/ |

## 六、功能演示流程

### 用户购票
1. 首页浏览，点击「电影」/「演出」分类，点进票品详情。
2. 选择场次 → 进入选座页，点击可选座位（高亮变红），右侧显示已选与总价。
3. 点击「确认选座」，座位锁定并生成待支付订单。
4. 在确认页点击「确认支付」，模拟支付成功 → 跳转电子票券页，得到本订单唯一的 16 位核销码（一个订单无论几张票共用一个）。
5. 「我的订单」中可查看订单状态、查看电子票、申请退票。
6. 申请退票后，订单状态变为「退票审核中」，等待商家处理。

### 商家运营
1. 用 `shop01` 登录后自动进入商家后台。
2. 「票品管理」新增/编辑/上架下架票品；进入「场次」添加场次并生成座位。
3. 「座位/票价」可按行或全场调价、重置座位状态。
4. 「销售订单」查看全部销售明细。
5. 「退票审核」处理用户退票申请：通过 → 退款并回收座位；驳回 → 订单恢复。
6. 「票券核销」输入用户电子票上的核销码，**整单一次性核销**（本订单全部座位）；核销后订单状态显示【已核销】，重复核销会被拒绝。

## 七、常见问题

| 问题 | 解决 |
|---|---|
| `Access denied for user 'root'` | `config.py` 中 `DB_PASSWORD` 填错，改成正确密码 |
| `Unknown database` | 未执行 `python init_db.py` |
| 端口被占用 | `app.py` 中改 `port=5000` 为其他端口 |
| 想换数据库账号 | 修改 `config.py` 中 `DB_USER` / `DB_PASSWORD` |

## 八、说明与扩展

- **支付**：本系统为演示环境使用**模拟支付**。对接真实微信/支付宝需企业商户资质，在 `routes/user.py` 的 `pay()` 中接入对应 SDK 即可。
- **订单超时**：待支付订单 15 分钟未支付自动取消，座位自动释放（可在 `config.py` 的 `ORDER_TIMEOUT` 调整）。
- **二维码**：电子票默认展示核销码；安装 `qrcode` 后可扩展为二维码图片。
